# Security

Report a vulnerability through [GitHub private security advisories](https://github.com/madeinusmate/sgp-circuit-redesign/security/advisories/new) on this repository.

Leave secrets out of issues and pull requests. That includes `.env`, Firebase admin keys, service-account JSON, and access tokens. The `VITE_` values in `.env.example` are public in the browser bundle. A server or admin secret does not belong in one of them.
