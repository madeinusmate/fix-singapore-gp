# Firestore only for published layouts, hosted on Vercel

Drafts stay in the browser. A Google sign-in is required only to publish or upvote, and the published layout is a Firestore document. The leaderboard ranks by a `votes` counter on each layout, kept honest by security rules: a vote is a batch that creates or deletes `layouts/{id}/votes/{uid}` and moves the counter by exactly one. That keeps ranking a single indexed query, so Firestore still fits; Supabase would only win if the homepage had to filter and sort on several computed fields. The site itself is hosted on Vercel. Google sign-in stays on the site's own domain via a `/__/auth` rewrite to the Firebase auth host, because a cross-domain redirect breaks on mobile Safari. That rewrite is doing real work even though it looks like a spare redirect.
