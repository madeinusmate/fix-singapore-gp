# A lap board belongs to one revision

The lap board shows personal bests for the layout's current path and racing sense only. Changing either one clears the board that drivers see. A rename, a recolor, a new photo, or a retune of the sim does not, and a sim retune does not rewrite times already stored. Resetting when the length changes would keep a time for a corner that has moved. Resetting on every save would wipe the board when the photo changes. Keeping every historical time would show a result for a lap that no longer exists.
